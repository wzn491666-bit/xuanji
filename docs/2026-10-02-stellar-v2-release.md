## 真实能力范围

原生命令包括新建/历史/模型/强度/思考显示/权限/任务/文件/终端/配置/
技能/停止/重连。断线时可执行本地菜单与重连；改变模型必须有可用会话。
这些命令不会当成普通提示词发送，错误参数保持输入并显示用法。

已核对 bundled 3.27.0 的工作流为 plan、write-plan、plan-close、team、
team max、scout、council、galaxy，以及 review 的 max/l1/l2/l3。
技能来自当前会话启用列表。项目命令仅发现文件名，正文由天枢执行时解析。
目录参考页的未接入命令保持只读，没有伪造为可执行能力。

status/cache/context/verify/evidence/mission/todo/tasks/jobs 打开已有工作台
信息；不会冒充桌面 TUI 的完整管理操作。独立 goal/plan/domain 控制 API
仍需专门接入，不属于本轮已完成能力。

## 无损真机回归

覆盖安装，保留数据；不卸载、不清数据、不删除文件。不在报告中贴 API Key。

1. 确认安装版本 0.2.0 / 29，桌面图标已更新，天枢恢复运行中。
2. 连续新建对话：检查手绘恒星与两条轨道、星域短句；相邻欢迎词不重复，每个会话仅一句。键盘、模型更新、重连不重抽；恢复空会话保留原句。顶部无“璇玑”二字，底部无三个快捷按钮。
3. 点顶部模型，切换到思考页。检查无底部强度入口，拖动到两端、按压到最大档，滑块横向不越界。
4. 强度提交期间显示应用中，确认后显示实际档位；关闭重开仍对应会话值。失败应回到原值并报错。
5. 依次设置全部折叠、半折叠、全部展开，检查默认过程展示；展开仍为小字，默认半折叠仅最新四行。
6. 聚焦输入框，检查胶囊、额外星光和键盘避让。发送时底部渐隐、顶部原位浮现，不平移。
7. 执行下方只读提示词，验证一轮过程聚合、原始事件可展开、最终回复单列。
8. 过程中展开并向上/下阅读，新事件不把视口拉回。停止后发送简单提示词，验证再次发送。
9. 输入 /model list 打开模型面板；/thinking preview 更改默认显示；/settings 打开配置。操作不产生一坨提示词消息。
10. 从命令面板调用当前实际启用技能；命令先填入短输入，保留用户填写任务的机会。
11. 工作台和设置反复滑到底部、展开服务商、开关键盘，检查无抽搐、无背景缺口或露出对话框。
12. 历史 A → /new → 返回 A，已执行命令不恢复成草稿；切换历史恢复中不显示欢迎页。
13. 断线时尝试 /reconnect 和 /settings，入口可用；/model 真正切换不可被静默接受。
14. 浅/深色、系统大字体、窄屏和动画关闭分别检查；录屏可看观感，帧耗时仍需真机测量。
