## 星轨脉冲与思考区更新

- 按璇玑恒星品牌原创实现“星轨脉冲”：细轨道、沿轨光点和最高档金色日冕替代大面积多色渐变罩层。发送时上方轨道原位渐显、下方淡出，结束后收束。
- 思考强度滑条保留真实功能：拖动预览，松手提交天枢会话接口并回读核对，成功后保存；忙碌和不支持的模型仍受原能力限制。轨道加宽，按压只轻微放大恒星滑块，固定标题高度，避免档位文字切换引发尺寸弹动。
- 总执行栏与每个思考子段各自保存展开选择。打开总栏不再强制展开全部子段；全局“展开思考总览”默认打开总栏，子段仍可分别查看。
- 半折叠显示最新约四行，全文展开仍使用 `13sp` 小字与 `21sp` 行高。预览只解析有界尾部；首次展开先准备正文，再固定本次动画目标，避免异步空正文突然撑高。后续流式更新保留上次解析结果，不重启点击过渡。
- 尊重系统减少动态效果设置：动画倍率为零时停止自定义循环、思考展开即时完成，保留静态视觉与等待状态；退到后台或对话被其它面板遮挡时暂停背景装饰动画。

## 真机验收

保留现有用户文件和设置。使用新的专用验收会话，不卸载、不清理数据、不锁屏。

1. 进入设置中的“项目与开源文档”。逐一打开技术架构、第三方来源、完整组件表、发布清单、LICENSE、NOTICE 和原许可证，确认能滚动、返回、搜索许可证。在无模型连接时文档也应能读取。
2. 新会话发送 `/todo`，再发送 `/todo add 璇玑版本验收`。在原生清单中开始、编辑、完成该验收条目，记录显示的真实 ID；关闭面板再打开，检查结果保留。
3. 让天枢执行一个无文件修改的简短说明任务，中途停止。待状态结束后打开 `/todo`，添加另一验收条目，确认不因之前的停止报保存失败。正常退出再打开应用后检查清单。
4. 新会话使用 `/plan` 发起只制定步骤、不得修改文件的任务。等待结束后从历史重新打开，检查用户命令仍为短文本，模型执行结果正常。
5. 请天枢列出 Android 浏览器工具并打开 `https://example.com`，读取真实标题和页面内容。在浏览器保持可见时，经批准测试刷新 / 后退 / 前进和标签页切换 / 关闭。每次动作后重新读页；拒绝审批不应被报告为成功。
6. 打开一篇较长的公开文档，要求天枢使用分页读取到末尾并记录实际 `page.nextOffset`。旧快照不得继续操作；密码、文件上传、frame / shadow DOM 等边界不能伪称已支持。
7. 记录发停、历史重开、首页星域对齐与最终天枢状态；错误保留脱敏日志和版本号，不发送 API Key 或 token。
8. 打开模型菜单，拖动思考强度并松手，确认应用状态结束后档位保留；关闭再打开菜单，核对实际档位。检查最高档日冕、两端滑块边界、忙碌禁用和不支持的模型状态，不能只凭光效变化判定请求成功。
9. 在新会话取得真实思考内容，分别测试总栏与子段开合：总栏打开后子段不全部展开，全文仍是小字；关闭再打开总栏，子段选择保留。切换三种默认展示模式，检查最新约四行和历史浏览位置。
10. 观察发送后顶部原位渐显与底部淡出；打开工作台、回到桌面再返回，检查装饰动画暂停 / 恢复。按手机系统设置关闭动画后检查静态显示与思考展开。此人工观察不替代帧时间测量，测试后恢复原系统设置。
