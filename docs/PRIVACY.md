# 隐私说明

说明日期：2026-10-03。适用范围：本仓库中的璇玑 Android 客户端源码，以及按该源码在本机构建的调试版本。正式对外分发的 APK 必须在构建后重新核对本文与发布清单，并按网络观测结果更新。

璇玑是本地优先的客户端：项目本身不运营账号系统、广告 SDK 或遥测后端。对话推理、搜索、网页访问和模型服务都由使用者自行配置。本文只描述当前源码可以确认的数据流，不代表第三方组件或外部服务作出了同样的隐私承诺。

## 本机保存的数据

- API Key：Android 端模型密钥使用 Android Keystore 的 AES-GCM 密文保存；搜索密钥使用独立别名。应用禁用系统备份，通知与日志不显示真实 Key。天枢运行时另有自己的 `secrets-store`（AES-256-GCM、0600 权限、文件或系统密钥库后端），与 Android Keystore 是不同层，不能视为同一套托管。
- 会话与事件：对话、thinking、工具调用、审批结果和待办等记录保存在应用私有目录中的天枢数据目录。它们默认不离开设备，除非相应内容被发送给模型服务或被命令主动读取。
- 附件：从系统选择器复制的文件写入应用私有 rootfs（`/root/.xuanji/attachments/`），原文件保留。图片支持 PNG / JPEG / WebP / GIF，单图片上限 10 MiB，其它文件 8 MiB，每类最多 4 个。
- 运行环境：PRoot、Ubuntu rootfs、Node.js 和天枢安装在应用私有存储；卸载应用或清除应用数据会删除这些本地数据。设备上其它应用的共享存储不在此范围。
- 浏览器：内置 WebView 会按网页行为保存站点 cookie 和站点存储；清除应用数据会同时清除这些内容。

## 可能离开设备的数据

| 数据 | 触发方式 | 目的地 | 说明 |
| --- | --- | --- | --- |
| 对话、thinking 请求、附件 | 发送消息或附带图片 / 文档 | 使用者配置的模型服务，以及可选 vision 服务 | 是否发送、发给谁由当前配置决定；文档一般以 runtime 路径交给天枢读取 |
| 搜索词 | 使用网页搜索 | 所选搜索服务、公共 MCP 或自建 SearXNG | 每个引擎使用单独配置的密钥与端点 |
| 网页导航与子资源 | 打开浏览器或让工具访问 URL | 目标站点及其子资源提供方 | 站点自身的 cookie、存储与追踪行为不受本项目控制 |
| Shell / 文件工具产生的网络请求 | 执行命令或天枢工具 | 命令实际访问的外部端点 | 仅在审批允许的范围内执行；访问目标由命令内容决定 |
| 模型服务所需的中转信息 | 使用命令行、登录或第三方 MCP | 对应服务商 | 服务商条款与日志策略由对方决定 |

## 用户控制

- 模型、vision、搜索与 MCP 由使用者选择或配置；项目方不在应用内预置自己的密钥或中转账户。
- 可在设置中更换或清除密钥。清除应用数据会删除本机会话、密钥、附件与 rootfs 数据。
- Root、Shizuku、无障碍、共享存储等 Android 权限由系统设置授予，可随时在系统设置中撤销。
- 浏览器授权、工具审批与危险命令确认在每次执行前展示；拒绝后不会继续请求。

## 第三方与限制

- 天枢 (Tianshu-harness)、Node.js / npm 依赖、Ubuntu 包、Termux PRoot / 原生库、Shizuku 与第三方 MCP 各有自己的实现与网络行为，本项目不能替它们作出保证。
- 当前仓库源码未包含项目自建的遥测上报端点；仅凭源码不能证明所有上游组件都不会联网。正式发布前必须按 [发布清单](open-source/RELEASE_CHECKLIST.md) 的真机网络观测项核实外部连接。
- 外部服务的使用条款、配额与数据处理规则由服务商决定；开源客户端许可证不替代服务授权。
- 本文不构成法律意见，也不替代各第三方组件的许可证与隐私文件。
