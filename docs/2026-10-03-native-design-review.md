## 本轮修复

- 星笺上的星域入口可点开原生详情，包含官网核对的全部 16 个星域的
  角色、认知纪律及官方链接。查看详情不会改变真实会话星域；关闭后

- 展开的思考统一采用 13sp / 21sp 排版，包括表格、代码块及行内代码。
  普通回复的表格和代码保持既有字号。
- 离线验收 Activity 增加模型、思考、命令、发送/停止和断线工作台场景。
  工作台实例仅在未配置的模拟器上创建；不满足条件时跳过，避免误启动崩溃。
- 截图脚本为每次采集分配唯一文件名，检查导出成功信息、App 节点和

## 渲染诊断边界

早期模拟器截图为黑屏，不能计为通过。正式入口与离线页随后均取得
可见截图，但打开思考面板时曾出现 ANR。已保留堆栈：主线程等待
HardwareRenderer，RenderThread 停在模拟器 qemu OpenGL 的
glCreateProgram 调用；切换 host 后端又出现 System UI ANR。
这说明当前模拟器图形链路不能提供可靠的性能基线，尚不能据此排除
App 性能问题，也不能外推为手机会卡顿。未改动生产绘制代码来掩盖它。

未完成本轮真机验证：模型弹窗、滑块两端/最大档动效、半折叠思考滚动、
Markdown 表格、历史侧栏、发送/停止恢复、设置底部与工作台边界、
小屏、大字体、深色、键盘避让。用户已选择自行测试。
