# 璇玑 0.2.1 真机验收提示词

先覆盖安装 `xuanji-0.2.1-debug.apk`，保留应用数据。确认版本
0.2.1 / versionCode 30，然后将下面整段交给手机上的测试助手。
首次配置及 API Key 输入由用户自己完成；不要把密钥放入测试报告。

```text
请对璇玑 com.xuanji.android 做一次无损 UI 回归。
不要卸载、清数据、删除、格式化、清理或编辑任何用户文件，不锁屏。
不要读取或输出 API Key，不修改模型服务商配置。
记录原有思考强度与显示方式，测试后恢复。

1. 确认版本 0.2.1 / 30，等待天枢运行中。记录主页截图。
2. 新建对话，观察手绘恒星、星环与轨道；点击“星笺·星域”一行。
   确认详情显示角色、纪律、官方链接，关闭后欢迎词不变。
   再新建两次对话，相邻欢迎词不重复；每个会话仅有一句星笺。
3. 从顶部模型入口打开思考页。拖动滑条至两端和最高档，观察按压、
   松手、静置时的粒子和渐变；滑块不得超出滑条。记录应用中和最终档位，
   关闭重开核对实际保存值。不要把仅有视觉变化判为真实配置成功。
4. 设置半折叠，发送下面的“排版测试消息”。思考默认只展示最新约四行；
   点击展开后，正文、表格和代码仍为小字。上下滑动，不得被拉回思考开头。
   再检查全部折叠和全部展开，然后恢复原设置。
5. 检查回复的标题、灰底行内代码、表格、代码块和列表，不能显示原始
   Markdown 分隔符或出现文字重叠。点击复制，确认勾选反馈后图标恢复。
6. 聚焦输入框，检查胶囊尺寸、星光和键盘避让；发送时顶部光效应原位
   浮现，底部渐隐，不应把整片光从底部平移到顶部。
7. 发送“请写一篇较长的多代理调度说明，不要调用工具”，生成中点击停止。
   记录停止中、停止完成和是否还能重新发送。
   再发送：请只回复“0.2.1 对话链路正常”，不要调用工具。
8. 打开加号，确认图片、文件、命令与技能入口存在。输入并执行
   /model list、/thinking preview，确认本地控制生效，不出现一大坨提示词。
   打开历史侧栏，切换刚才的会话，确认回复与欢迎词对应正确。
9. 执行 /settings；反复滑到底部、展开服务商栏目，再滚到底部。
   记录是否抽搐。不要保存或更改服务商配置。检查工作台四个标签页，
   底部背景不能缺一块，内容不能与系统导航栏重叠。
10. 关闭面板、退到桌面再回来。确认天枢恢复运行中，恢复原思考设置。

排版测试消息：
请不要调用工具。解释“发送、停止、恢复”的区别，用一个标题、一个三列
表格、一个有序列表、一个引用、一个短代码块和灰底行内代码呈现。
表格各列为“动作、预期状态、观察点”。不要声称你实际检查过应用。

输出：逐项通过/失败/未测；版本号；关键截图；发送与停止结果；
思考强度是否真实保存；滚动和布局问题；错误原文与发生步骤。
没有证据的项目标记未测，不要推断通过。报告不含任何密钥。
```
