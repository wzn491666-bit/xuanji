# Stellar 0.2.0 Update

## Approved Direction

The user's 15-point request authorizes this update to the previously reviewed
UI. White native product canvas, compact capsule composer, unified top model /
effort / thinking-display controls. Remove the chat header brand text and three
empty-state shortcuts. Rebuild the orbital stellar mark and launcher icon.
Welcome copy: 16 original short couplets inspired by the official stellar
portraits and docs/concepts. Three restrained compositions use a real bundled
Chinese artistic fonts. A decorative "星笺" label never claims to change
the runtime domain, whose official default is qiming.
Keep real controls, history, approvals, attachments, send/stop and Tianshu data.

## Boundaries

No deletion, uninstall or clearing user data. Preserve API credentials without
logging them. User files are untouched. Full Tianshu integration uses actual
bridge capabilities; unsupported desktop commands require explicit native
handling or remain clearly distinguished. Permission state never becomes fake.
No new recurring background animation while app is hidden or motion is off.
Animation frame state is read during drawing rather than message measurement.
