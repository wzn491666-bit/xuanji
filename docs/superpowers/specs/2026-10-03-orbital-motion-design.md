# 璇玑星轨动效与思考展开设计

用户于 2026-10-03 选择星轨脉冲方向。品牌基础是璇玑已有的恒星、星环与星域；不从 Gemini 等产品复制特效代码或素材。

## 视觉

白色正文背景保留，去掉大面积彩色渐变浮光。底部以宽幅弧线、有限的沿轨光点与青蓝 / 钢灰 / 暖金层次表达当前思考强度。输入获得焦点时星点与轨道轻微增强；发送后底部逐渐收束，在上方回复起点浮现独立冠环，不平移整片光效。

强度控件保留真正模型档位、提交回调与无障碍语义，换为轨道仪式。档位增大时轨道数量、运行速度与光点密度渐变；最高档只有一次慢变冠冕，不采用快速闪烁。原生 Slider 保证点选、拖动、键盘与 TalkBack；视觉端点不能越界。

## 思考过程

总展开与子展开状态分离。总段展开后每个子思考默认半折叠约四行；全局折叠模式下子段默认折叠。点击具体子段才显示全文，仍用 13sp 小字。折叠 / 重开总段保留子选择，流式新增段不继承其它段的全文展开。

只在展开状态变更时进行高度过渡；每个文本 delta 不重新启动展开动画。用户点击展开暂停自动跟随，避免动画期间被拉到底部。系统关闭动画时即时呈现；后台、页面被覆盖时停止装饰帧循环。

## 验证与归属

原生单元测试覆盖默认策略、子选择、不同流式段和真实强度映射。编译及静态检查后由用户真机检查动画和帧表现；不能在没有帧数据时声称达到固定帧率。保留 Apache / 第三方归属与源码发布边界。新的视觉差异不被描述成法律免责保证。
