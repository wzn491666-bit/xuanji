## 已接入

| 命令 | Android 行为 |
| --- | --- |
| `/goal` | 打开原生目标表单或当前目标面板 |
| `/goal <目标> [--max N] [--budget 分钟] [--criteria JSON]` | 初始化 agent、设置真实 tracker，再提交官方目标启动消息 |
| `/goal-status` | 查看目标、生命周期、轮次、时间预算、判据及最近核验结论 |
| `/goal-pause` | 暂停后续自主轮次 |
| `/goal-resume` | 恢复原 tracker，提交真实继续执行消息 |
| `/goal-cancel`、`/cancel-goal` | 取消目标，保留当前会话 |
| `/goal-criteria` | 读取目标判据 |
| `/plan-list` | 从真实接口读取工作区计划列表，草稿单独呈现 |
| `/plan-view [slug]` | 查看计划全文；先停止天枢自动批准倒计时 |
| `/plan-edit [slug]` | 编辑待审批计划，保存走官方 PUT 接口 |
| `/plan-approve [slug] [方案]` | 批准计划；由官方审批接口启动执行，Android 不重复提交启动消息 |
| `/plan-reject [slug] [反馈]` | 提交完整修改反馈，由天枢处理修订轮次 |

无 slug 的计划命令打开计划列表，可继续选择文档、方案及审批操作。
新目标不能直接覆盖尚未结束的目标；需要先取消再创建。
目标暂停或取消不等于中断当前模型轮次，当前轮次可使用聊天页停止按钮。
目标面板分别展示 tracker 状态和天枢实际运行状态，启动失败在面板报告。

## 交互与可靠性

- Markdown 全文、待审批/已批准/已执行/已驳回状态，保持现有原生视觉规范。
- 固定审批与保存区域，支持键盘避让、滚动编辑、方案选择及确认。
- 查看与暂停可以在任务运行时使用；审批、编辑、创建与恢复受空闲状态限制。
- 检查 `ok:true`、目标回显及 HTTP 错误，不能把请求发出当作执行成功。
- 启动消息使用正式 prompt 接口和独立请求 ID；失败重试保留原载荷和幂等键。
- 聊天与历史展示简短目标命令，官方目标驱动提示仍完整交给天枢。
- 会话 generation 和服务 token 限制旧回执更新；关闭面板后迟到回执不重新弹出。

## 已知范围

`/goal-criteria set` 当前没有官方 HTTP 接口。本次明确拒绝该子命令，
新目标可通过 `--criteria` 提供判据；不会用重建目标冒充修改而重置预算。
上游可能异步提取判据，面板以实际 `goal_state` 回显为准。
`/plan-template`、胶囊、完整 todo 写操作和目录中其它未接入项仍需继续实现。
没有宣称全部天枢命令已完成接入。
